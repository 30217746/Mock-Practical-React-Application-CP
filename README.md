# Film Database

You are building the database for a small film review website using Prisma and PostgreSQL.

## Start here

Read these files in this order:

1. **[docs/setup.md](docs/setup.md)**: install packages, start the database and make your `.env` file. Do steps 1 to 3 only.
2. **[docs/tasks.md](docs/tasks.md)**: the task sheet. It tells you what to build, what to hand in and the steps to follow for every table.
3. **[docs/sample-data.md](docs/sample-data.md)**: the directors, films, actors and reviews to use in your seed script.
4. **[docs/relationships.md](docs/relationships.md)**: the template you fill in to explain each relationship in your ERD.

## What you will hand in

| Deliverable                     | Where it goes           |
| ------------------------------- | ----------------------- |
| Database schema                 | `prisma/schema.prisma`  |
| Seed script                     | `prisma/seed.ts`        |
| ERD screenshot                  | `docs/erd.png`          |
| Relationship explanations       | `docs/relationships.md` |
| Work log                        | `WORKLOG.md`            |

Full details are in [docs/tasks.md](docs/tasks.md).
